# User Guide (Members)

## Getting started
- Create your account / receive access from the organization
- Log in using your credentials
- Complete your profile information

## Your dashboard
As a member, you can typically:
- View your groups and group activity
- Access training modules and track progress
- View announcements
- Submit or view business reporting (depending on enabled features)

## Groups
Inside a group you can:
- View group details and membership
- See leadership members
- Participate in group decisions (proposals + voting)

## Proposals + Voting
- Proposals are created to help groups make documented decisions.
- You can vote on proposals where voting is enabled.

## Group wallet (if available)
- Members can view:
  - Group wallet address
  - Balances and recent transfers
- Leadership may manage outgoing transfers via an approval process.

## Getting help
If something looks wrong (can’t log in, missing group, etc.), contact an admin and share:
- What page you were on
- What you tried to do
- Any error message shown
